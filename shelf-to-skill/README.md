# Shelf to Skill

A plan for getting real value out of the ~145 books in my main bookcase. The goal is a **new job applying machine learning to energy** (solar, battery storage, the grid), with public projects as proof.

- [`plan/index.html`](plan/index.html): the full plan as a page (tracks, weekly rhythm, roadmap, habits, ways to earn from it). Open it in a browser.
- [`books.md`](books.md): every book, grouped by track, with its role.
- [`calendar/block1.ics`](calendar/block1.ics): the first 12-week block as repeating calendar events (already on Google Calendar).

## How the books get used

Nobody reads 145 books cover to cover. Each book gets a role:

| Role | About | How |
|---|---|---|
| Work through | 12 | Exercises and code, one at a time |
| Read | 45 | Cover to cover, 30 minutes a night |
| Reference | 75 | Open the chapter a project needs |

## Weekly rhythm (about 9.5 hours, Pacific time)

| When | What |
|---|---|
| Mon–Wed 7:30–8:30 pm | Deep study: the current ML spine book, with exercises |
| Thu 7:30–8:30 pm | Algorithms practice |
| Sat 10:30 am–1 pm | Build session: a small public project on energy data, plus a write-up |
| Sun–Fri 9:30–10 pm | Light reading |
| Sun 5–5:30 pm | Weekly review |

Japanese (Genki) and a math book rotate in an existing Saturday 8–10 am block.

## Publishing

Every Saturday project goes three places:

1. **GitHub**: the code and notebook.
2. **A blog** (Substack, Medium or GitHub Pages): a 500–800 word write-up covering the problem, the data, what I tried, what worked, and a chart or two.
3. **LinkedIn**: a short post with one chart and the blog link.

Write-ups are original work: my own code and explanations, never copied pages or exercise solutions.
